## Purpose

Pins the exact npm v3 dependency tree for VitePress and MathJax 3 so `npm ci` builds are deterministic locally, in code-repo CI and in GitHub Pages deployment.

## Code Commentary

Records npm `lockfileVersion: 3` across 213 `packages` entries (root `""` plus 212 `node_modules/*` packages), resolving `vitepress@1.6.4` (with `vite@5.4.21` and `vue@3.5.46`) and `markdown-it-mathjax3@4.3.2` (with `mathjax-full@3.2.1`) matching [site/package.json](package.json.md).

## Relationships

Referenced as `cache-dependency-path` and consumed by `npm ci` in [CI `site-build-check`](../.github/workflows/quality.yml.md) and `ar-rh-proof-skeleton/.github/workflows/pages.yml`. Regenerate only from [site/package.json](package.json.md).
