# .gitignore

## Governing Overview

[Repository overview](overview.md)

## Purpose

Excludes local Python/Node tool artifacts and compiler-generated VitePress documentation outputs from Git tracking and AR onboarding.

## Code Commentary

Ignores Python caches, virtual environments and build outputs (`__pycache__/`, `.venv/`, `.pytest_cache/`, `.ruff_cache/`, `dist/`, `build/`), Node/VitePress build directories (`site/node_modules/`, `site/docs/.vitepress/cache/`, `site/docs/.vitepress/dist/`), all `rh-build-site` generated paths (`site/docs/stages/`, `site/docs/concepts/`, `site/docs/assets/`, `site/docs/public/`, `site/docs/index.md`), and OS editor files.

## Relationships

Keeps outputs emitted by [the site compiler](src/rh_pipeline/site/compiler.py.md) out of Git while leaving tracked VitePress configuration and theme files under `site/docs/.vitepress/` and [site/package-lock.json](site/package-lock.json.md) version-controlled.
